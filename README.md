# Graduation Project – Senin Bahçen

This repository contains the full documentation and deliverables of the graduation project **“Senin Bahçen”**, which focuses on designing a **sustainable and inclusive agricultural business model**.

The project was developed collaboratively by a two-member team and aims to promote **fair income distribution**, **women employment**, and **access to organic food** in Türkiye through a social entrepreneurship approach.

---

## 📌 Project Overview

**Senin Bahçen** is a social business concept that connects local producers and consumers through a sustainable agricultural value chain.  
The project integrates business model design, financial planning, and social impact considerations within an academic framework.
